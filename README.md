# DELTA GREEN — Оперативный архив

Локальная интерактивная энциклопедия по Delta Green: правила, создание агента, проверки,
бой и погоня, рассудок, бестиарий, гипергеометрия, «Дом», конспирация, история, «Раскол»
и материалы куратора.

Всё работает офлайн, без установки и без сервера: откройте `index.html` двойным щелчком.
Шрифты, стили и данные лежат рядом, интернет не нужен.

---

## Быстрый старт

1. Откройте `index.html` (Edge, Chrome, Firefox).
2. Разделы — в левом меню. Поиск — **Ctrl+K** или **/**.
3. Кости — кнопка в правом нижнем углу или клавиша **D**.
4. Создайте агента: **Вербовка → Генератор**, после сохранения откроется **Архив персонажей**.
5. Бестиарий: **Неизвестное → Бестиарий**. Нажмите на рамку статблока, чтобы прикрепить
   своё изображение существа.

> Если браузер не сохраняет изображения существ при открытии через `file://`,
> запустите архив через локальный сервер (см. «Изображения и сохранение»).

## Что внутри

| Раздел | Содержимое |
|---|---|
| **00 Брифинг** | О системе, тон, механика, материалы для вдохновения |
| **01 Агент** | Правила создания на одной странице, сводка профессий и организаций, генератор, архив с цифровыми листами |
| **02 Протоколы** | Проверки, бой, погоня, арсенал, снаряжение, рассудок, «Дом» |
| **03 Угрозы** | Заражение пониманием, гипергеометрия, бестиарий, конструктор угроз, конспирация, история, «Раскол» |
| **04 Куратор** | Создание игры, кампании и операции, ширма, советы |

Интерактивные инструменты:

- **Генератор агента** — шесть шагов, расчёт ОЗ/ОВ/ОР/ТН, профессии, восемь бонусов +20%,
  связи и мотивации. Сохранение сразу открывает агента в архиве.
- **Архив персонажей** — поиск по досье, портреты и карточки состояния. Цифровой лист:
  урон и лечение ОЗ/ОВ/ОР, проверка ОР по формуле (`1/1к6`), автоматические проверки
  при 2 ОЗ и потере 5+ ОР, Точка Надлома, связи с кнопками −1/−1к4/−1к6, отметки неудач
  и прокачка навыков (+1% или d100 → +1к10), журнал операций, экспорт JSON.
  Кнопка **«Офиц. бланк»** печатает данные на двух страницах официального бланка Delta Green,
  кнопка **«PDF»** сразу скачивает заполненный PDF.
- **Пульт костей** — формулы (`2d6+2`), проверки d100 с модификаторами, SAN-броски,
  критические успехи и провалы.
- **Бестиарий** — фильтры по уровню угрозы, поиск, статблоки с изображениями,
  пользовательские угрозы.
- **Конструктор угроз** — генерация статблока по уровню опасности, редактирование,
  сохранение в базу, экспорт в буфер.
- **Домашние сцены** — трекер Personal Pursuits с бросками и журналом.
- **Ширма** — плотные таблицы проверок, боя, рассудка, ядов, болезней и травм.
- **Поиск** — по заголовкам и тексту всех досье.

## Изображения и сохранение

- Агенты, угрозы, журнал сцен и настройки хранятся в `localStorage`.
- Изображения существ и портреты — в `IndexedDB` (ключ `dg-media`), с резервным
  сохранением в `localStorage`, если IndexedDB недоступен.
- Данные привязаны к браузеру и компьютеру. Очистка данных сайта их удалит.
- Экспорт агента — кнопка **Экспорт** в листе (JSON). Импорт — в базе агентов.
- Изображения в экспорт агента не входят.

Если изображения не сохраняются при `file://`:

1. Откройте терминал в папке архива.
2. Выполните `python -m http.server 8765` (или `py -m http.server 8765`).
3. Откройте `http://localhost:8765/`.

Так браузер получает нормальный origin, и IndexedDB работает без ограничений.

## Структура

```
delta-green/
├── index.html              оболочка: меню, поиск, пульт костей
├── build.mjs               сборка страниц и поискового индекса
├── CONTENT-GUIDE.md        правила оформления контента
├── src/
│   ├── pages/              исходники страниц (HTML-фрагменты + META)
│   └── data/               профессии и бестиарий (JS-данные)
├── assets/
│   ├── css/                дизайн-система и стили официального бланка
│   ├── js/                 app, dice, characters, threats, tools, media, official-sheet
│   ├── data/               сгенерированные pages.js, search.js, bestiary.js
│   ├── sheet/              page1.webp, page2.webp — официальный бланк агента
│   └── fonts/              локальные woff2 (Oswald, PT Serif, JetBrains Mono, Caveat)
└── sources/                извлечённые тексты PDF (не входит в поставку? см. ниже)
```

`sources/` с текстами книг в эту папку не входит — он остаётся в рабочей папке
проекта и нужен только для сборки/редактирования контента.

### Пересборка после правок

```bash
node build.mjs
```

Сборка читает `src/pages/**/*.html`, проверяет META, генерирует
`assets/data/pages.js` и `assets/data/search.js`, склеивает `src/data/bestiary*.js`
в `assets/data/bestiary.js` и пишет `build-report.json`.

### Добавить страницу

1. Создайте `src/pages/<раздел>/<id>.html`.
2. Начните файл с блока `<!--META { ... } META-->` (образцы — в `CONTENT-GUIDE.md`).
3. Укажите `group`, `order`, `parent`, `num`, `code`.
4. Запустите `node build.mjs`.

## Технические заметки

- Без фреймворков и сборщиков: ванильные HTML/CSS/JS, hash-роутинг.
- Работает из `file://`, но для IndexedDB надёжнее локальный сервер.
- Печать: кнопка в верхней панели печатает текущую страницу. В листе агента кнопка
  **«Офиц. бланк»** выводит две страницы A4 на оригинальном бланке: фон — пустой
  официальный лист, поверх него — данные агента, навыки, связи, оружие и заметки.
- Адаптивность: десктоп, планшет, телефон. На телефоне меню — по кнопке слева.
- Все шрифты локальные, с кириллицей.
