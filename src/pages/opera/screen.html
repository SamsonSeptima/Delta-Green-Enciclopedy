Главное правило ширмы

Если ответ неочевиден и не критичен — не ищите таблицу. Назначьте шанс (20 / 40 / 60 / 80), попросите бросок и двигайтесь дальше. Таблицы нужны для напряжения, а не для юридической точности.

Когда бросок не нужен

  • Действие спокойное, безопасное и повторяемое.
  • У агента достаточно времени и инструментов.
  • Провал ничего не меняет и никого не ставит под угрозу.
  • Игрок описал план, который просто работает.

Бросок нужен там, где есть риск, цена или неопределённость.

Урон и состояние

  • Потеря ≥ ½ текущих ОЗ за атаку — оглушение; ТЕЛ×5 в начале хода, чтобы восстановиться.
  • 1–2 ОЗ — проверка ТЕЛ×5, иначе постоянная травма.
  • 0 ОЗ — смерть, если куратор не решит иначе. ОЗ не уходят ниже 0.

Смертельность

Рейтинг Летальности — вероятность сразу снизить ОЗ цели до 0. Бросок d100 ≤ рейтинг: цель уничтожена. Провал: урон = сумма двух d10.

Существо крупнее человека Летальностью не убивается: получает урон, равный рейтингу.

Летальность отменяет только укрытие (автопровал). Броня успешный бросок не отменяет — она снижает урон при провале.

Радиус поражения

  • +20% к попаданию, если это взрыв.
  • Попадание: проверка Летальности для всех в радиусе.
  • Выжившие и промахнувшиеся — подавлены.
  • Подавление: спрятаться или упасть ничком следующим действием, иначе −1 ОР (если нет адаптации к насилию).

Быстрые проверки

Один взгляд: проверка

  1. Есть риск и неопределённость? Нет — просто опишите результат.
  2. Какой навык? Если нет — характеристика ×5.
  3. Шанс 20 / 30 / 40 / 60 / 80.
  4. Модификатор: +20, −20, −40.
  5. d100 ≤ итог. Дубль — крит или провал.
  6. Опишите что изменилось, а не только «получилось».

Один взгляд: бой

  1. Инициатива по ЛОВ.
  2. Одно действие за ход.
  3. Атака: d100 ≤ навык + модификаторы.
  4. Защита: Уклонение / рукопашный бой, если агент ждал.
  5. Урон: кубик + бонус СИЛ − броня.
  6. Летальность: d100 ≤ рейтинг = смерть.
  7. 2 ОЗ — без сознания; 0 — смерть.

Один взгляд: рассудок

  1. Событие: насилие / беспомощность / паранормальное.
  2. Потеря: 0/1, 0/1D6, 1/1D8 и т.п.
  3. d100 ≤ текущий ОР — успех.
  4. Вычтите потерю; при 5+ за раз — временное помешательство.
  5. Дошли до ТН — новое расстройство.
  6. 0 ОР — персонаж потерян.
