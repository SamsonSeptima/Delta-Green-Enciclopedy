# DELTA GREEN — руководство по контенту

Ты пишешь фрагменты локальной интерактивной энциклопедии по Delta Green (русский язык).
Каждая страница — отдельный HTML-файл в `delta-green/src/pages/`. Сборка `build.mjs` читает
мета-блок и тело, складывает всё в `assets/data/pages.js`. Файлы `src/pages/**` — единственное,
что ты создаёшь. CSS и JS уже готовы; не добавляй свои стили и скрипты.

## 1. Формат файла

```html
<!--META
{
  "title": "Заголовок страницы",
  "nav": "Короткое имя для меню",
  "subtitle": "Одна фраза под заголовком.",
  "kicker": "РАЗДЕЛ 02 · ПРОТОКОЛЫ",
  "code": "DG-02-01",
  "num": "02.1",
  "group": "rules",
  "order": 31,
  "parent": "checks",
  "summary": "Одно предложение для карточки-хаба.",
  "tags": ["Проверки", "Кости"]
}
META-->

<p class="lede">Вводный абзац. 2–4 предложения. Задаёт тон и объясняет, зачем эта страница.</p>
...
```

Поля:
- `group`: `intro` | `agent` | `rules` | `world` | `handler`
- `order`: число, порядок внутри группы (задаётся в задании).
- `parent`: id родительской страницы или отсутствует.
- `num`: номер досье для меню, например `02.1`.
- `hidden`: true только для служебных.
- META — строго валидный JSON, без комментариев и висячих запятых.

Тело — только фрагмент (без `<html>`, `<head>`, `<body>`, без `<h1>`). Заголовок H1 собирается из META.

## 2. Тон

- Сухой, точный, «ведомственный» язык документов. Второе лицо для правил: «агент делает…».
- Атмосфера X-Files / папки с грифом: не мистический пафос, а усталая констатация.
- Не выдумывай правила. Все числа, названия навыков, оружия и существ — из источников.
- Если правило опционально или это совет, а не закон — помечай `ОПЦИЯ` или `СОВЕТ`.
- Не копируй длинные абзацы книг дословно. Пересказывай; таблицы, статблоки и термины можно переносить.
- Игровые термины: ОЗ, ОВ, ОР, ТН, СИЛ, ТЕЛ, ЛОВ, ИНТ, ВОЛ, ХАР, проверка, бросок, Куратор, агент.
- Избегай англицизмов там, где есть русский термин, но названия операций/организаций оставляй как в книге.
- Не используй смайлы, восклицательные знаки, «вы можете почувствовать».

## 3. Обязательные компоненты

### Секция
```html
<section class="section" id="osnovy">
  <header class="sec-head">
    <span class="sec-num">01</span>
    <h2>Основы</h2>
    <p class="sec-sub">Короткая подпись, необязательно.</p>
  </header>
  ...
</section>
```
Нумеруй секции по порядку: 01, 02, 03… `id` — латиницей, для якоря.

### Сетка и карточки
```html
<div class="grid g2">   <!-- g2 / g3 / g4 -->
  <div class="card">
    <div class="card-h">Название <span class="card-tag">МЕТКА</span></div>
    <div class="card-b"><p>Текст.</p></div>
  </div>
</div>
```
Карточки — для параллельных правил, а не для всего текста. Не больше 6 карточек подряд.

### Таблицы
```html
<div class="table-wrap">
  <table class="tbl">
    <caption>Подпись таблицы</caption>
    <thead><tr><th>Колонка</th><th class="num">%</th></tr></thead>
    <tbody><tr><td>Значение</td><td class="num">50</td></tr></tbody>
  </table>
</div>
```
`class="tbl compact"` — плотная. `class="table-wrap tall"` — прокрутка. Числа — `class="num"`.

### Схема действий
```html
<ol class="flow">
  <li><b>Объявите намерение</b><p>Что именно делает агент.</p></li>
  <li><b>Бросьте</b><p>1d100 ≤ навык.</p></li>
</ol>
```

### Выноски
```html
<div class="callout rule"><span class="callout-t">ПРАВИЛО</span><p>…</p></div>
```
Варианты: `rule`, `warn`, `danger`, `note`, `quote` (цитата с `<span class="src">источник</span>`).

### Сворачиваемый блок
```html
<details class="fold"><summary>Дополнительно: …</summary><div class="fold-b"><p>…</p></div></details>
```

### Кнопки бросков (работают через общий пульт)
```html
<button class="roll" data-roll="1d100" data-target="60" data-label="Проверка Бдительности">Проверить 60%</button>
<button class="roll" data-roll="1d6" data-label="Урон">1d6</button>
<button class="roll" data-san="1/1D6" data-label="Потеря рассудка">SAN 1/1D6</button>
```
`data-target` — итоговый шанс с учётом модификатора. Для SAN текущий ОР подставляется из последнего значения.

### Прочее
- `<span class="tag">МЕТКА</span>`, `<span class="tag red">…</span>`
- `<span class="stamp">СЕКРЕТНО</span>`
- `<span class="redact" data-t="Текст">скрытый текст</span>` — использовать редко, 1–2 раза на страницу.
- `<dl class="kv"><div><dt>Термин</dt><dd>Значение</dd></div></dl>`
- `<p class="margin-note">Заметка на полях</p>` — не больше одной на страницу.
- `<span class="kicker">…</span>` — мелкая надпись.
- `<hr class="hr-rule">` — разделитель.
- `<div class="divider">Заголовок</div>`

### Ссылки
Внутренние: `<a href="#/combat/firefight">Бой</a>`. Никаких внешних ссылок и картинок.

### Плейсхолдер инструмента
```html
<div data-tool="threatgen"></div>
```
Доступные: `chargen` (генератор), `chardb` (архив досье), `charsheet` (цифровой лист), `threatgen`, `bestiary`, `pursuits`.
Не добавляй вокруг них свои обёртки.

## 4. Чего нельзя

- `<script>`, `<style>`, inline `style="..."`, iframe, img, внешние шрифты.
- Свои CSS-классы, которых нет в этом руководстве.
- `<h1>`, `<html>`, `<body>`.
- Длинные цитаты из книг. Максимум 1–2 короткие атмосферные цитаты на страницу.
- Придуманные названия навыков. Используй канонические: Атлетика, Бдительность, Бюрократия,
  Бухгалтерия, Антропология, Археология, Артиллерия, Агентурная разведка, Вождение, Выживание,
  Иностранный язык, Информатика, Искусство, История, Криминалистика, Криминология, Медицина,
  Маскировка, Навигация, Наука, Оккультизм, Огнестрельное оружие, Оружие ближнего боя,
  Первая помощь, Пилотирование, Подрывное дело, Поиск, Психотерапия, Радиоэлектронная разведка,
  Ремесло, Рукопашный бой, Скрытность, Тяжёлая техника, Тяжёлое оружие, Убеждение, Уклонение,
  Фармацевтика, Хирургия, Юриспруденция, Военная наука, Плавание, Верховая езда.

## 5. Плотность и структура

- 1 страница = 1 тема. 6–12 секций, 8–20 тыс. знаков.
- Сверху — `.lede` (2–4 предложения), затем самая важная таблица/схема, затем детали.
- Каждая секция должна отвечать на один вопрос. Если ответ длинный — таблица или карточки.
- Правила, которые часто ищут за столом (модификаторы, урон, потеря ОР), — в начале, не в конце.
- В конце — `details` с «редкими случаями» или ссылками на смежные страницы.

## 6. Источники

Тексты извлечены из PDF в `sources/`:
- `agent.txt` — «Справочник агента» (рус.). Печатные страницы указаны в тексте.
- `handler.txt` — «Справочник куратора» (машинный перевод, местами кривой — правь формулировки).
- `digest.txt` — «Выжимка правил» (4 стр.).
- `screen.txt` — «Ширма куратора» (5 стр.).
- `tricks.txt` — «Хитрости и приёмы куратора».
- `launch.txt` — «Запуск игры: вспомогательные цели».
- `quickstart.txt` — «Краткий инструктаж».
- `vazhno.txt` — «Важно знать» (часть страниц — сканы, текст может отсутствовать).

Ищи по ключевым словам через grep, например:
`grep -n "Очки Здоровья" sources/agent.txt`. В тексте есть маркеры `===== PAGE n =====`
(это PDF-страницы; печатная страница обычно на 2–4 меньше).

## 7. Самопроверка перед сдачей

1. META — валидный JSON; `id` не указан в META (он берётся из пути файла).
2. Нет `<h1>`, `<script>`, `style=`, `img`.
3. Все открытые теги закрыты; таблицы с `<thead>` и `<tbody>`.
4. Все секции пронумерованы и имеют `id`.
5. Числа и правила сверены с источником; нет выдуманных механик.
6. Файл сохранён в UTF-8.
